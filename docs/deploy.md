# 배포와 도메인 연결 가이드

클래스허브(Streamlit 앱 + Supabase)를 인터넷에 공개하고, GitHub 학생 혜택으로 받은 도메인을 연결하는 순서입니다.

> **이 레포가 이미 준비한 것**: `Dockerfile`, `.dockerignore`, `.streamlit/config.toml`, 공개 배포용 데모 버튼 숨김 플래그(`HIDE_DEMO_LOGINS`). 로컬에서 컨테이너를 빌드·실행하고 실제 DB 로그인까지 확인했습니다.
> **직접 하셔야 하는 것**: 호스팅 계정 만들기·결제 수단 등록, 도메인 발급, DNS 설정. 모두 본인 계정이 필요합니다.

---

## 0. 공개 전 필수 보안 점검 (꼭 먼저)

이 앱은 데모로 만들어져서 그대로 공개하면 위험한 부분이 있습니다.

| 항목 | 상태 | 해야 할 일 |
| --- | --- | --- |
| 데모 로그인 버튼 | 버튼 하나로 **관리자 로그인**이 됨 | 컨테이너는 `HIDE_DEMO_LOGINS=1`이 기본값이라 숨겨짐. 다른 방식으로 배포하면 환경 변수를 직접 설정 |
| 데모 계정 비밀번호 | `supabase/seed.sql`(공개 레포)에 적혀 있음 | **공개 전에 반드시 교체** (아래 SQL) |
| DB 권한(RLS) | 데모용 전체 허용 | 키는 서버(Streamlit)에서만 쓰여 브라우저에 노출되진 않지만, 실서비스 수준이 아님. 후속: Supabase Auth 기반 RLS |
| 회원가입 | 누구나 가능, 이메일 인증·횟수 제한 없음 | 스팸 가입 가능. 필요 시 가입 제한 추가 |

### 데모 계정 비밀번호 교체

Supabase 대시보드 → SQL Editor에서 실행합니다. `새비밀번호`는 직접 정하세요(8자 이상).

```sql
-- 관리자
update lms_users
set password_hash = extensions.crypt('새비밀번호', extensions.gen_salt('bf'))
where login_id = 'admin';

-- 교수 전체(P2001~P2008)와 데모 학생이 필요 없으면 삭제하거나 같은 방식으로 교체
update lms_users
set password_hash = extensions.crypt('새비밀번호', extensions.gen_salt('bf'))
where login_id like 'P200%';
```

## 1. 도메인 받기 (GitHub 학생 혜택)

GitHub 학생 혜택 페이지(<https://education.github.com/pack/offers>)에서 확인한 도메인 혜택입니다. 혜택 내용은 바뀔 수 있으니 신청 전에 페이지에서 다시 확인하세요.

| 업체 | 혜택 |
| --- | --- |
| Namecheap | `.me` 도메인 1년 + SSL 1년 |
| Name.com | `.dev` `.app` `.live` 등 25개 이상 확장자 중 선택 |
| .TECH | `.tech` 도메인 1년 |

**받는 순서**
1. GitHub 학생 계정으로 위 페이지에 로그인합니다.
2. 원하는 업체의 혜택 링크를 눌러 이동합니다.
3. Name.com은 **먼저 Name.com에서 로그아웃**한 뒤 GitHub 페이지의 링크로 들어가 로그인해야 혜택이 적용됩니다. Name.com 계정 이메일은 이미 쓴 적 없는 주소여야 합니다.
4. 결제 화면에서 도메인 금액이 0원으로 적용됐는지 확인합니다.
5. 무료 기간은 1년이므로 이후 갱신은 별도 결제입니다. **자동 갱신 설정을 확인**하세요.

> `.dev`·`.app`은 HTTPS가 필수인 확장자입니다(호스트가 인증서를 발급해 주면 문제없음).

## 2. 어디에 배포할까

| 선택지 | 비고 |
| --- | --- |
| **Streamlit Community Cloud** | 가장 쉽지만 **커스텀 도메인을 지원하지 않는 것으로 보임**(커뮤니티 답변 기준, 공식 문서로 확인 필요). `*.streamlit.app` 주소만 가능 |
| **Microsoft Azure** | 학생 혜택으로 $100 크레딧(만 18세 이상, 카드 불필요라고 안내됨). 컨테이너를 올릴 수 있음 |
| **Heroku** | 학생 혜택으로 월 $13 크레딧을 24개월. 컨테이너 배포 가능 |
| GitHub Pages | **사용 불가** — 정적 사이트 전용이라 Streamlit(서버 필요)을 올릴 수 없음 |

커스텀 도메인을 쓰려면 Streamlit Community Cloud 말고 **컨테이너를 올릴 수 있는 호스트**(Azure, Heroku 등)를 고르세요. 어떤 호스트든 같은 `Dockerfile`을 씁니다.

> 호스트 콘솔의 메뉴 이름과 CLI 명령은 자주 바뀌므로 이 문서에는 적지 않았습니다. 각 호스트의 "컨테이너 배포"와 "커스텀 도메인" 공식 문서를 함께 보세요.

## 3. 로컬에서 컨테이너 먼저 확인

```bash
docker build -t classhub-lms .
```

환경 변수로 Supabase 정보를 넣어 실행합니다(이미지에는 비밀 값이 들어 있지 않습니다).

```bash
docker run --rm -p 8501:8501 \
  -e SUPABASE_URL="https://<프로젝트>.supabase.co" \
  -e SUPABASE_KEY="<publishable 키>" \
  classhub-lms
```

브라우저에서 <http://localhost:8501> 을 열어 로그인과 데이터 로드를 확인합니다. 데모 버튼이 보이지 않는 것이 정상입니다.

---

## 4. 호스트에 올릴 때 설정할 값

| 환경 변수 | 값 | 비고 |
| --- | --- | --- |
| `SUPABASE_URL` | Supabase 프로젝트 URL | 필수 |
| `SUPABASE_KEY` | publishable 키 | 필수. 호스트의 **비밀 값/환경 변수 설정**에 넣고 Git에는 올리지 않기 |
| `HIDE_DEMO_LOGINS` | `1` | Dockerfile 기본값. 직접 설정할 필요는 없음 |
| `PORT` | 호스트가 지정 | Heroku·Render처럼 포트를 주입하는 호스트는 자동으로 따라감 |

**꼭 확인할 것: WebSocket.** Streamlit은 WebSocket으로 화면을 갱신합니다. 호스트에 WebSocket 설정이 있고 꺼져 있다면 켜세요. 꺼져 있으면 화면이 계속 "로딩 중"에서 멈춥니다.

## 5. 도메인 연결

호스트에 배포하면 `xxxx.호스트도메인` 형태의 기본 주소가 생깁니다. 그 주소로 앱이 열리는 것을 먼저 확인한 뒤 연결하세요.

1. **호스트 콘솔에서 커스텀 도메인 추가**: `www.내도메인.me`처럼 입력하면, 호스트가 **연결 대상 주소(CNAME 값)** 와 필요하면 **검증용 TXT 값**을 알려줍니다.
2. **등록업체(Namecheap/Name.com)의 DNS 설정**에서 레코드를 추가합니다.

   | 타입 | 호스트(이름) | 값 |
   | --- | --- | --- |
   | CNAME | `www` | 호스트가 알려준 대상 주소 |
   | TXT | 호스트가 알려준 이름 | 호스트가 알려준 검증 값(요구하는 경우만) |

3. **루트 도메인(`내도메인.me`, www 없음)** 은 CNAME을 쓸 수 없습니다. 둘 중 하나로 처리하세요.
   - 등록업체가 제공하는 **URL 리다이렉트**로 `내도메인.me` → `https://www.내도메인.me`
   - 호스트와 등록업체가 **ALIAS/ANAME** 레코드를 지원하면 그것을 사용
4. **HTTPS 인증서**: 대부분의 호스트가 도메인 확인 후 자동 발급합니다. 호스트 콘솔에서 "인증서 발급됨"을 확인하세요.
5. DNS 전파는 보통 몇 분~몇 시간 걸립니다. 확인:

   ```bash
   dig +short CNAME www.내도메인.me
   ```

   호스트 주소가 나오면 반영된 것입니다.

## 6. 문제 해결

| 증상 | 확인 |
| --- | --- |
| 화면이 계속 로딩됨 | 호스트의 WebSocket 설정, 프록시 타임아웃 |
| "서버에 연결하지 못했습니다" | `SUPABASE_URL`/`SUPABASE_KEY` 환경 변수 오타, Supabase 프로젝트 일시정지 여부(무료 플랜은 장기간 미사용 시 일시정지) |
| 로그인 화면 하단에 "샘플 데이터 모드" | Supabase 환경 변수가 전달되지 않음 |
| 도메인이 안 열림 | `dig`로 CNAME 반영 확인, 인증서 발급 완료 여부 |
